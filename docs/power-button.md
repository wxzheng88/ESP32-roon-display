# BAT-PWR 电源按键说明（V4.0 非触摸版）

## 程序行为（v3.1 起）

| 操作 | 效果 |
|------|------|
| 关机状态下短按 BAT-PWR | 开机（硬件行为，程序无需参与） |
| 开机状态下长按 BAT-PWR 3 秒 | 关机：屏幕显示 "Powering off..." 后断电 |
| 电池供电时长按 | **真正断电关机**（电池通路被切断） |
| USB 供电时长按 | **深度待机**：屏幕熄灭、功耗最低；再按 BAT-PWR 立即开机 |
| 开机后前 10 秒长按 | 无效（防止"按键唤醒后手没松开又被关掉"） |
| 按 RESET 键 | 硬件复位重启（接 ESP32 的 EN 脚，任何时候都有效，与程序无关） |
| 开机状态下短按 | 无动作（防止误关机） |

## 为什么"长按不关机"？（原理解释）

你的板子电源结构（来自官方 V4.0 原理图）：

- BAT-PWR 按键信号（SYS_OUT）→ 接到 **ESP32 GPIO16**（按下=低电平）
  和板载 CH32V003 电源协处理器。
- 电池通路受 **SYS_EN** 控制（I2C 芯片 0x24 输出寄存器 bit5）：
  高电平=保持开机，低电平=切断电池 → 关机。
- **USB 供电走的是另一条独立通路，电路设计上软件无法切断。**

所以：

1. **如果之前插着 USB 测试**——长按/双击都不可能关机，这是电路设计，
   不是程序问题。USB 供电时程序会转为"深度待机"（屏幕熄灭），
   再按一下 BAT-PWR 就开机。
2. **如果用电池供电**——现在长按 3 秒会真正断电关机。
3. 出厂固件自带一个手势：**电池供电时"双击 BAT-PWR"= 直接断电**（硬件行为），
   这个也可以用。

## 串口诊断（115200）

开机时会打印电源系统状态：

```
[PWR] button idle (GPIO16 high, OK)
[PWR] reg04(INPUT)=0x.. reg07(RTC_INT)=0x..
[PWR] battery 3.87V
```

运行中每 60 秒打印一次电池电压 `[PWR] battery x.xxV`。
如果显示板不在了或没接电池，这两行会自动跳过，不影响运行。

## 可调参数（RoonCoverDisplay.ino 顶部）

| 常量 | 默认 | 含义 |
|------|------|------|
| `PWR_OFF_HOLD_MS` | 3000 | 长按多少毫秒触发关机 |
| `PWR_BOOT_GRACE_MS` | 10000 | 开机后多少毫秒内忽略按键 |
| `PWR_BTN_GPIO` | 16 | 按键所在 GPIO（勿改，除非硬件变动） |
| `BATT_LOG_MS` | 60000 | 电池电压打印间隔 |
